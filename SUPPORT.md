# Command Palette LLM Support

Use [GitHub Issues](https://github.com/maxnevans/CommandPaletteLLM/issues) for
bug reports, feature requests, and support questions. Search existing issues
before opening a new one.

Include the Windows version, PowerToys and Command Palette versions, installation
source, CPU architecture, and reproducible steps. Never include API keys,
provider credentials, confidential prompts, or other personal information.

Command Palette LLM is preview software. Microsoft does not provide support for
this third-party extension.
